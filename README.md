# はこスタ 1.5.0

地域活動をポイント・バッジで記録し、現地クーポンや参加証明を集めるDelta Chat用ミニアプリです。

自治会・公民館・学校・店舗・避難所・イベントなどに使えます。会場名、活動、スタンプ画像、特典は管理者が編集できます。

## はじめ方

1. 主催者が `hakosta-1.5.0.xdc` をDelta Chatの運用グループへ送ります。
2. 配布者が対応するDelta Chatで、まず1台から開きます。管理者が自動設定されます。
3. 管理者が会場・活動・特典を保存し、管理者キーと設定のバックアップを安全に保管します。
4. スタッフ鍵を担当者ごとに発行し、個別に渡します。
5. 参加者は同じグループの同じアプリを開いて申請し、受付で確認を受けます。

受付中は管理者のアプリを1台で開き、鍵を解除しておいてください。スタッフの処理は管理者が自動で最終確定します。

## 操作マニュアル

- [ブラウザーで読む](hakosta.html)

12章構成です。利用者は4〜6・9章、スタッフは7〜8章、管理者は3・10〜11章を中心にお読みください。図は説明用の画面イメージです。

## 主な機能

- 来場スタンプと、活動ごとの防災・地域活動ポイント
- 来場バッジ、会場横断バッジ、署名付き参加証明
- 受付QRと、受取・使用期限を分けた現地クーポン
- スタンプ特典交換、残数の消費またはリセット、履歴とCSV
- 管理者によるスタッフ鍵の個別発行・期限設定・失効
- 管理者画面の受付と一括承認、キーと設定のバックアップ・復元

## 運用上の注意

TinyBox圏内を自動判定する機能ではありません。QRとスタッフの対面確認を併用します。QR時刻は端末時計の自己申告で、時刻偽装を完全には防げません。

オフライン会場で同期するには、TinyBoxのLANとメールサーバーなど、端末間で到達できる通信経路が必要です。別グループや別メッセージのアプリは同じ台帳になりません。

設定バックアップは、別台帳の参加履歴・スタンプ残数・利用者IDを移す機能ではありません。元の台帳と記録JSONは別途保管してください。旧キーだけのファイルには設定が入っていません。

管理者キーは管理者だけが保管し、スタッフにはスタッフ専用鍵を渡します。避難所で支援を受ける条件をポイント数に結び付けないでください。

## 1.5.0の変更

管理者ページに承認待ち受付を追加しました。管理者キーと保存済み設定をまとめて保存・復元できます。旧履歴JSONからの設定復元にも対応します。JSONの項目順変更に対応した送信確認と、アプリ由来の英語の終了警告の削除も含みます。

## 確認した範囲

署名・権限・受付・復元・送信処理などのモデルテストを実施しています。PC・Android実機のカメラ、鍵保管、Delta Chat間の実通信は未確認です。実運用の前に少人数で試してください。
